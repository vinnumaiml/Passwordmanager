Engineered for Android

Built with True Zero-Knowledge Security

Every security control in Nova Vault is implemented natively on device using established cryptographic standards.

Envelope Encryption

A random 256-bit Data Encryption Key (DEK) encrypts vault items under AES-256-GCM. The DEK itself is wrapped with an Argon2id-derived Key Encryption Key (KEK).

AES-256-GCM Argon2id (64 MiB) Unique Nonces

Hardware Keystore & Biometrics

Locally unlocks vault access using hardware-backed Android Keystore keys guarded by Class 3 BiometricPrompt (fingerprint or face). Invalidation occurs if enrollment alters.

AndroidKeyStore BiometricPrompt CryptoObject

Android Autofill Service

Deep OS-level integration through Android's Autofill Framework. Intelligently parses AssistStructure node hierarchies to autofill credentials with zero copy-pasting.

AutofillService AssistStructure Inline Suggestions

RFC 6238 TOTP Authenticator

Built-in two-factor code generator supporting HMAC-SHA1/256/512 and Base32 secrets. Includes live 30-second countdown dials and instant QR code scanning via CameraX.

RFC 6238 CameraX QR Base32

Password & Passphrase Generator

Generate cryptographically random passwords or EFF large-wordlist passphrases using hardware SecureRandom with real-time Shannon entropy strength rating.

EFF Wordlist SecureRandom Entropy Meter

Security Center & HIBP Breach Check

Continuous audit for weak, reused, and old credentials, plus k-anonymity Have I Been Pwned check where only the first 5 characters of a SHA-1 hash are queried.

k-Anonymity HIBP API Health Audit
Cryptographic Blueprint

Zero-Knowledge Envelope Model

Neither your vault master password nor your unencrypted credentials ever leave your device.

Cryptographic Envelope Flow

Nova Vault isolates your master password entirely from server authentication. The server authenticates your account, but can never decrypt your vault data.

1
Master Password
Entered locally into memory as CharArray. Never saved to disk or network.
2
Argon2id KDF
64 MiB memory, 3 iterations, 4 lanes, 32-byte salt derive 256-bit Key Encryption Key (KEK).
3
DEK Unwrapping
KEK unwraps the random 256-bit Data Encryption Key (DEK) via AES-256-GCM authentication.
4
Item Decryption
DEK decrypts vault items in memory. Buffers zeroed immediately after use.
Dual-Credential Safeguard: Resetting your cloud account password does not decrypt or overwrite your vault. If the master password is lost, access can only be restored using your offline 32-byte Recovery Kit.

How to Install on Android

Installing an APK downloaded directly from your browser takes four simple steps.

01

Download APK

Tap the Download for Android button above. If prompted by Chrome/Firefox that "File might be harmful", tap Download anyway.

02

Enable Browser Install

Open the downloaded NovaVault.apk. When Android asks for permission, tap Settings and toggle on "Allow from this source".

03

Verify Checksum

Optionally verify integrity before installing using PowerShell or terminal:

Get-FileHash NovaVault.apk
04

Launch & Setup

Open Nova Vault, create your account, configure your Master Password, and save your 32-byte offline Recovery Kit.
